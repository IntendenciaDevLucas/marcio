# Logos da faixa de marcas

Os dez SVGs já estão incluídos e são servidos localmente. Para substituir, mantenha os nomes:

`fiat.svg`, `volkswagen.svg`, `chevrolet.svg`, `renault.svg`, `ford.svg`, `toyota.svg`, `hyundai.svg`, `jeep.svg`, `nissan.svg`, `honda.svg`.

Use SVG com fundo transparente e viewBox ajustado ao desenho. O CSS padroniza a cor prata e preserva a proporção. Edite `src/data/brands.ts` para adicionar ou remover marcas. Os caminhos não começam com `/`: o componente usa o base do Vite para funcionar em `/marcio/` no GitHub Pages.

Fontes dos arquivos:

- Nove logos: [diegojasso/car-logos-SVG](https://github.com/diegojasso/car-logos-SVG), licença MIT preservada em `LICENSE.txt`.
- Renault: [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/renault.svg), distribuição [CC0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).

As marcas pertencem aos seus respectivos titulares. Os logos identificam as marcas atendidas, sem afirmar vínculo de concessionária ou assistência autorizada.
